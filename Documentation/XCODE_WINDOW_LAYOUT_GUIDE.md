# 🪟 Xcode AI 窗口布局优化指南

## 🎯 分离 AI 窗口的方法

### 方法 1: 直接拖拽（最简单）✨

```
1. 找到 AI 面板的标题栏
   ┌─────────────────────────┐
   │ ⚡ Xcode AI         [×] │  ← 这里
   ├─────────────────────────┤
   │ 聊天内容...             │
   └─────────────────────────┘

2. 按住标题栏并向外拖拽

3. 释放 → 独立窗口！
```

### 方法 2: 使用快捷键

- **⌘⇧A** - 显示/隐藏 AI 助手
- 显示后拖拽分离

### 布局 B: 双显示器并排（推荐）🌟

```
┌─────────────────────────┐    ┌─────────────────────────┐
│   显示器 1 (主屏幕)      │    │   显示器 2 (辅助)        │
│                         │    │                         │
│   Xcode 主窗口          │    │   AI 助手窗口           │
│                         │    │                         │
│   ┌──────┬────────────┐ │    │   ┌───────────────────┐ │
│   │ Nav  │ Editor     │ │    │   │ 聊天历史          │ │
│   │      │            │ │    │   │                   │ │
│   │ 文件 │ 代码编辑器  │ │    │   │ 完整对话          │ │
│   │ 树   │            │ │    │   │                   │ │
│   │      │            │ │    │   │ 可以滚动查看      │ │
│   └──────┴────────────┘ │    │   │ 之前的消息        │ │
│                         │    │   └───────────────────┘ │
│   ┌───────────────────┐ │    │                         │
│   │ Debug Console     │ │    │   ┌───────────────────┐ │
│   └───────────────────┘ │    │   │ BUILD_FIX_GUIDE   │ │
│                         │    │   │ (参考文档)        │ │
└─────────────────────────┘    └─────┴───────────────────┘
```

**优点：**
- ✅ 可以同时看到代码和 AI 对话
- ✅ 不需要来回切换窗口
- ✅ AI 窗口可以保持在视线内
- ✅ 便于复制代码建议

## 🎨 其他 Xcode 窗口布局技巧

### 调整编辑器布局

#### 单编辑器模式
```
View → Editors → Standard Editor (⌘↩)
```

#### 双编辑器并排模式
```
View → Editors → Assistant (⌘⌥↩)
```

**用途：** 同时查看两个文件（例如：模型和测试）

```
┌──────────────────┬──────────────────┐
│ Distance.swift   │ DistanceTests.swift │
│                  │                  │
│ struct Distance {│ @Test func ...   │
│   let yards: ... │ #expect(...)     │
└──────────────────┴──────────────────┘
```

---

### 显示/隐藏面板快捷键

```
⌘0        - 隐藏/显示 Navigator（左侧）
⌘⌥0       - 隐藏/显示 Inspector（右侧）
⌘⇧Y       - 隐藏/显示 Debug Area（底部）
⌘⇧A       - 隐藏/显示 AI Assistant
```

---

### Focus Mode（专注模式）

```
View → Hide Toolbar (⌘⌥T)
⌘0 (隐藏 Navigator)
⌘⌥0 (隐藏 Inspector)
```

**效果：** 全屏代码编辑，AI 窗口独立浮动

```
┌─────────────────────────────────────────┐
│                                         │
│         全屏代码编辑器                   │
│                                         │
│         // 专注写代码                   │
│                                         │
│                                         │
└─────────────────────────────────────────┘

     ┌─────────────┐
     │ AI 助手     │  ← 浮动在右上角
     │ (小窗口)    │
     └─────────────┘
```

## 📱 在 MacBook 上的最佳实践

### 如果只有一个笔记本屏幕：

#### 选项 1: AI 窗口缩小并固定在角落

1. 分离 AI 窗口
2. 调整大小到 1/4 屏幕
3. 放在右上角或右下角
4. 保持可见但不遮挡代码

```
┌─────────────────────────────────────┐
│  Xcode 主窗口                ┌─────┐│
│                             │ AI  ││
│  代码编辑区域                │     ││
│                             │     ││
│                             └─────┘│
│                                    │
│  ┌───────────────────────────────┐ │
│  │ Debug Console                 │ │
│  └───────────────────────────────┘ │
└─────────────────────────────────────┘
```

#### 选项 2: 使用 macOS Spaces（虚拟桌面）

1. **Space 1:** Xcode 主窗口
2. **Space 2:** AI 助手 + 文档浏览器
3. 使用 **⌃←** / **⌃→** 快速切换

## 🖼️ Mission Control 配置

启用三指轻扫切换 Spaces：

```
System Settings → Trackpad → More Gestures
✅ App Exposé
✅ Mission Control
```

**工作流：**
1. 在 Space 1 编写代码
2. 三指向右滑动到 Space 2 查看 AI 建议
3. 三指向左滑动回到 Space 1 应用建议

## 💾 保存窗口布局

Xcode 会自动记住：
- AI 窗口的位置和大小
- 编辑器布局
- 面板显示状态

**但注意：** 对话内容不会保存！（见 CONVERSATION_PERSISTENCE_GUIDE.md）

## 🎯 现在就试试！

### 快速设置步骤：

1. **分离 AI 窗口**
   - 拖拽 AI 面板标题栏到外面

2. **调整大小**
   - 调整到舒适的宽度（建议 400-600px）

3. **放置位置**
   - 单显示器：右上角或右侧
   - 双显示器：第二个显示器

4. **在 Xcode 中**
   - ⌘0 隐藏 Navigator（需要时）
   - ⌘⌥0 隐藏 Inspector（需要时）
   - 给编辑器更多空间

5. **开始工作！**
   - 边看 AI 建议边修改代码
   - 不用来回切换窗口

## 🚨 解决构建错误优先！

设置好窗口后，请立即执行：

### 在终端运行诊断：

```bash
cd /path/to/MCaddie
chmod +x diagnose.sh
./diagnose.sh
```

### 或者直接查找重复文件：

```bash
find . -name "Item.swift" -not -path "*/.*"
```

### 然后按照 FIX_DUPLICATE_ITEM.md 修复！
